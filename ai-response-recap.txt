## 1. Rangkuman Riset (Agustus 2026)

- **`playwright-stealth` masih hidup di Python**: versi `2.0.2` (13 Feb 2026), maintainer `Mattwmaster58`. API lama `stealth_async(page)`/`stealth_sync(page)` **sudah dihapus** (error `cannot import name`). API baru = class `Stealth` yang membungkus *seluruh instance* Playwright: `with Stealth().use_sync(sync_playwright()) as p:` (sync) atau `Stealth().use_async(...)` (async). Tapi ini hanya patch level JS — README-nya sendiri bilang hanya lolos deteksi paling sederhana.
- **Alternatif yang jadi standar 2026**: **Patchright** (`pip install patchright`) — fork drop-in Playwright yang mem-patch di level **CDP** (fix `Runtime.enable` leak yang tidak bisa ditutup monkey-patching), hanya support Chromium. Rekomendasi launch: `launch_persistent_context(user_data_dir=..., channel="chrome", headless=False, no_viewport=True)`, jangan pasang UA/header custom. Lainnya: **Camoufox** (Firefox-based, kuat vs Turnstile), **curl_cffi** (impersonate TLS/JA4 tanpa browser — sangat cocok utk endpoint API Bbato/MangaFire), **nodriver/zendriver** (CDP langsung). Playwright-stealth JS dianggap lemah vs Cloudflare ML v9.
- **Best practice sync**: pakai `sync_playwright()` (bukan `asyncio.run`) — ini satu-satunya cara tanpa crash event loop di script `requests` sync. Pasang `page.on("response", handler)` **sebelum** `page.goto()`, baca body lewat `response.json()`.

## 3. Catatan integrasi

- **Cara pakai** (ganti blok `asyncio.run(...)` di `mangafire.py`/`bbato.py`): panggil langsung `fetch_chapter_html(url)` dan `get_images_from_network(url)` dari fungsi sync — tidak akan crash, dan bisa dipanggil berulang (browser dibuka-tutup tiap panggilan; utk produksi, cache browser via `launch_persistent_context`).
- **Install**: `pip install curl-cffi patchright` lalu `patchright install chromium`. Kalau pakai jalur playwright, cukup `pip install playwright playwright-stealth` + `playwright install chromium`.
- Handler khusus MangaFire sudah otomatis: `img[0]` jadi URL, `img[2]>0` ditandai `#scrambled_<offset>`, format sama seperti `mangafire.py`.

Catatan: stealth di 2026 hanya "setengah solusi" — untuk hasil stabil disarankan tambah proxy residensial + pacing acak.
