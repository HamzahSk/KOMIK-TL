Selesai. Modul Rust `font_style_rs/` dibuat dan sudah di-*compile* + diuji. Kode Python kamu tidak disentuh sama sekali.

**Struktur:**
```
font_style_rs/
├── Cargo.toml        # PyO3 0.21 + rust-numpy 0.21, release profile LTO
├── pyproject.toml    # backend maturin
├── src/lib.rs        # analyzer murni Rust
└── usage_example.py  # snippet pemanggilan
```

**Algoritma (`src/lib.rs`):**
- **Italic** — estimasi sudut kemiringan via *projection-profile peakiness*: crop di-shear pada 49 kandidat sudut (−24°..24°); sudut dengan proyeksi vertikal paling tajam (Σ count²) dipakai. Jika `|slant| >= italic_threshold_deg` (default `10.0`) → italic.
- **Bold** — dua sinyal geometris tanpa AI: (1) median *stroke width* dari approximate Euclidean distance transform (chamfer 1/√2) dinormalisasi oleh tinggi baris teks, (2) rasio tinta dalam bounding box. Jika `stroke_ratio >= 0.15` **atau** `density >= 0.40` → bold. Kedua threshold bisa di-*passing* sebagai argumen opsional.
- Binerisasi Otsu adaptif (otomatis menangani teks hitam-di-putih maupun putih-di-hitam), aman untuk crop uniform/kosong.

**Hasil uji** (render font asli + shear): normal → `{False, False}`, italic → `{True, False}`, bold → `{False, True}`, bold-italic → `{True, True}`. Kecepatan: ~0.7 ms untuk crop 300×60, ~0.16 ms untuk 120×40.
